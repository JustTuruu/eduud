# UI үгсийн сан (энгийн монгол үг)

Апп даяар нэг ойлголтыг нэг л үгээр нэрлэнэ. Зарчим: өдөр тутмын ярианы үг, богино, ойлгомжтой; англи үг, орчуулгын хэлц (calque), техникийн нэр томъёо хэрэглэхгүй. Товч нь хийх үйлдлээ нэрлэнэ ("Илгээх", "Цэнэглэх"). Алдааны мессеж нь юу болсныг ба юу хийхийг хэлнэ.

| Ойлголт | Хэрэглэх үг | Хэрэглэхгүй |
|---|---|---|
| token | **эрх** (бүтэн: саналын эрх) — "128 эрх" | токен, token |
| bid хийх | **Дуудлага худалдаанд оролцох** (богино: "Оролцох") | bid, санал өгөх, үнийн санал илгээх |
| bid (тоо) | **санал** — "214 санал" | bid |
| live | **Явагдаж буй** / "Одоо явагдаж буй" | шууд, LIVE, идэвхтэй |
| scheduled | **Удахгүй эхлэх** | товлогдсон |
| ended | **Дууссан** | хаагдсан |
| сүүлийн bidder | **Тэргүүлж байна: <нэр>** | тэргүүлэгч, last bidder |
| winner | **Ялагч** / "Та яллаа!" | |
| orders (хожсон бараа) | **Хожсон бараа** | Ялалт, захиалга |
| wallet | **Эрх цэнэглэх** (дэлгэц), профайлд "Миний эрх" | Данс, хэтэвч |
| soft-close сунгалт | "Хугацаа N секундээр сунгагдлаа" | soft-close |
| payDeadline | "Төлөх хугацаа: ..." | |
| OTP | **баталгаажуулах код** / "Утсанд ирсэн код" | OTP |
| нэвтрэх / бүртгүүлэх | **Нэвтрэх** / **Бүртгүүлэх** | |
| auction request | **Хүсэлт** / "Бараагаа дуудлага худалдаанд оруулах" | зохион байгуулах хүсэлт |
| feedback | **Санал хүсэлт** | |
| Ачааллаж байна | **Түр хүлээнэ үү…** | |
| сүлжээний алдаа | "Холболт тасарлаа. Дахин оролдоно уу." | |
| Retry | **Дахин оролдох** | |
